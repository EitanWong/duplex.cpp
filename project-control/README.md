# macOS controls

Run `./project-control/start.sh`, `status.sh`, `stop.sh`, or
`./project-control/minicpm.sh restart` from the project root.

These controls use the root `.venv`, `selected-profile.json`, `runtime/config.json`
and `releases/m5-integrated-v3/native/`. Configure and build first; see the
[root quick start](../README.md). Logs are written to `logs/`.

This controller is macOS-specific. See [NVIDIA development](../docs/nvidia.md)
for Windows and WSL2 bring-up.
